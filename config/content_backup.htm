一、Onshape：零組件繪製完成後，如何「切割」零件？

（一）什麼情況叫「切割零件」？

切割指的是：

  • 把 一個實體 Part 分成多個 Part

  • 或在零件上 去除材料，形成槽、孔、分件面

（二）常用切割方式（實務最重要）


1️⃣ Extrude → Remove（最常用）

適合：開孔、開槽、減重孔

步驟

  1. 建立 Sketch（畫出要切掉的輪廓）

  2. 點選 Extrude

  3. Operation 選 Remove

  4. 選擇切割深度（Blind / Through all）

📌 優點：最穩定、Webots 匯出前一定要乾淨


2️⃣ Split（把一個零件切成多個零件）

適合：
👉 一開始畫成整塊，後來才發現要分成「兩個會動的零件」

步驟

  1. 建立一個「切割平面」（Plane 或 Sketch）

  2. 使用 Split

  3. Target：選要被切的 Part

  4. Tool：選 Plane 或 Sketch

  5. 勾選 Keep both sides

📌 這個對 Webots 非常重要

因為 Webots 的關節 = 不同零件之間的運動


3️⃣ Boolean → Subtract

適合：用一個零件「當刀子」去切另一個零件

應用

  • 齒輪互咬

  • 特殊形狀挖空


4️⃣ Mate connector + Split（機構導向做法）

專業建議做法：

  • 先放 Mate connector（未來轉軸）

  • 再用它對齊切割面
    ➡️ 後續 Webots 關節軸方向才會完全正確

二、為什麼一定要切割零件？（這是關鍵觀念）

❌ 不切割的後果

問題 結果
所有零件是一體 Webots 無法加關節
沒有獨立質量 動態模擬錯誤
無法定義慣量 控制不穩

✅ 切割後你能做到

  1. 每個零件 = 一個剛體（Rigid Body）

  2. 可設定：

    • 質量（Mass）

    • 慣性（Inertia）

    • 碰撞形狀（Collision）

  3. 可加入：

    • Revolute joint（轉動）

    • Prismatic joint（滑動）

📌 一句話總結

「切割零件 = 把 CAD 變成物理系統」

三、Onshape → Webots 的正確銜接流程

Step 1️⃣ 在 Onshape 準備給模擬用的模型

✔ 每個會動的部件 = 獨立 Part
✔ 關節位置已用 Mate connector 對齊
✔ 不要留「裝飾性倒角」（減少計算負擔）

Step 2️⃣ 匯出 CAD

建議格式

  • STEP (.step)

  • 或 URDF + STL（進階）

⚠️ 不建議：

  • 單一 STL（會失去結構）

四、Webots：後續控制系統設計與動態模擬

四-1 Webots 裡你要建立什麼？

（一）剛體（Solid）

每個 Onshape Part → Webots 的一個 Solid

重要屬性：

  • mass

  • inertiaMatrix

  • boundingObject

（二）關節（Joint）

Onshape Webots
Mate (Revolute) HingeJoint
Slider SliderJoint

📌 關節軸方向必須與 Onshape 設計一致

（三）致動器（Motor）

RotationalMotor PositionSensor

四-2 動態模擬（Dynamic Simulation）你在模擬什麼？

1️⃣ 正向動力學（Forward Dynamics）

👉 給馬達扭矩，看會怎麼動

2️⃣ 逆運動學 + 控制

👉 給目標軌跡（例如畫蘋果 🍎）

  • 計算關節角度

  • 控制馬達追蹤

四-3 控制系統設計流程（實務版）

① 開啟物理

WorldInfo: basicTimeStep 16

② 馬達模式

motor.setPosition(target) motor.setVelocity(max_vel)

③ 加 PID（你之前已碰過）

error = target - sensor.getValue() torque = kp*error + kd*derr motor.setTorque(torque)

五、把三件事串成一句話（你現在該有的工程觀）

Onshape 切割零件
→ 定義「哪些東西會動」
→ 匯入 Webots 成為剛體
→ 用關節 + 馬達 + PID
→ 做真實的「動態模擬與控制」
